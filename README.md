# PassKeeper – менеджер паролей
**Статичный макет** приложения для хранения паролей. Реализован на чистом HTML и CSS без использования JavaScript.

## Функциональные возможности

- **Три экрана**: вход, главный со списком паролей, настройки.
- **Переключение между экранами** через псевдокласс `:target` – без JavaScript.
- **Форма входа** с полем Мастер-пароль: при пустом поле появляется визуальное сообщение об ошибке (используются `:invalid` и `:required`).
- **Главный экран**:
  - Верхняя панель (логотип, навигация Пароли и Настройки).
  - Сетка из 9 карточек паролей (CSS Grid, 3 колонки).
  - Каждая карточка содержит: иконку-букву, название сервиса, даты создания и последнего использования, логин, поле пароля (скрыто по умолчанию).
  - **Показ пароля** реализован через checkbox hack – по нажатию на Показать пароль отображается текстом.
  - Кнопка Копировать – визуальная имитация (без реального копирования).
- **Экран настроек**:
  - Блок Алгоритм шифрования: выпадающий список (AES‑128, AES‑256, ChaCha20, Twofish) и статическое описание.
  - Блок Смена мастер-пароля: форма с тремя полями (текущий, новый, подтверждение). Индикация слабой длины нового пароля (минимум 8 символов) через атрибут `pattern` и псевдокласс `:invalid`.

## Используемые CSS-техники (согласно ТЗ)

- **CSS-переменные** (`:root`) – для цветов, радиусов, теней.
- **Flexbox** – для выравнивания шапки, навигации, элементов внутри карточек.
- **CSS Grid** – для сетки паролей (3 колонки).
- **Псевдоклассы**:
  - `:hover`, `:focus`, `:focus-visible` – для интерактивных элементов.
  - `:target` – переключение экранов.
  - `:checked` – управление показом пароля (checkbox hack).
  - `:valid`, `:invalid` – стилизация валидных / невалидных полей ввода.
- **Псевдоэлемент** `::after` – для подчёркивания активного пункта меню.
- **Transition** – плавные анимации при наведении, появлении пароля.
